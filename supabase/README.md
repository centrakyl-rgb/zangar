# Supabase для Акыл центр

## Бесплатный старт

1. Создать проект на Supabase.
2. Открыть `SQL Editor`.
3. Вставить содержимое `schema.sql`.
4. Нажать `Run`.
5. Создать первого пользователя в `Authentication`.
6. Добавить ему профиль администратора:

```sql
insert into public.profiles (id, full_name, role)
values ('USER_ID_ИЗ_AUTH', 'Администратор', 'admin');
```

После этого можно подключать приложение к Supabase API.

## Что уже есть в схеме

- ученики;
- предметы;
- оценки;
- посещаемость;
- болезни;
- плановые уведомления;
- роли `admin` и `teacher`;
- RLS-политики, чтобы данные не были публичными.

## Важно

Не вставляйте `service_role` ключ в приложение или APK. В клиенте можно использовать только `anon public` ключ, а доступ ограничивать через RLS-политики.
